# Online Shopping Purchase Prediction

A machine-learning classification project that analyses online shopping
sessions and predicts whether a session results in a purchase
(`Revenue`).

-   Inspect and explore online shopping session data.
-   Prepare numerical and categorical features for machine learning.
-   Train and evaluate a purchase-intention classifier.
-   Document the workflow in a Jupyter Notebook.

## How to run

1.  Clone or download this repository.

2.  Place the authorised dataset CSV in the project data folder, or
    update the notebook's data path.

3.  Start Jupyter:

    ``` bash
    jupyter notebook
    ```

4.  Open the project `.ipynb` notebook.

5.  Update the CSV path in the data-loading cell if needed.

6.  Run **Kernel → Restart Kernel and Run All Cells**.

7.  Review the generated charts, evaluation metrics, and any saved
    artifacts.

## Typical workflow

1.  Load and inspect the data.
2.  Check missing values, duplicates, data types, and target
    distribution.
3.  Perform exploratory data analysis.

5.  Encode categorical variables and scale numerical variables when
    required.
6.  Train baseline and candidate classification models.
7.  Evaluate using accuracy, precision, recall, F1-score, confusion

## Loading a saved scaler

Only use this snippet if `online_shopping_scaler.pkl` is a trusted file
created by your own notebook, and run it from the directory containing
the file (or provide the correct path):

``` python
import joblib

scaler = joblib.load("online_shopping_scaler.pkl")
print("Scaler loaded successfully")
```

Pickle/joblib files can execute code during loading. Load only files
from a trusted source. A scaler transforms features; it is not
necessarily the trained classifier itself.

## Reproducibility and responsible use

-   Keep the random seed and split strategy documented.
-   Fit preprocessing on training data only to avoid data leakage.
-   Document Python and package versions for the final run.
-   Protect the dataset and any customer-related information.
-   Treat predictions as estimates, not certainty about individual
    customers.
-   Reassess the model if the input data distribution changes.
